# My military-style training workspace

My separate five-screen exploration uses the supplied visual reference: dark navy surfaces, restrained gold, square panels, a subtle grid, and compact structured module navigation. No ranks, XP, mascot, map, globe, or introduction video.

Open index.html for the combined overview, or each separate HTML page. Both light and dark themes are included. The acknowledgement notice is retained; this is a section demonstration, not the intended or final layout. Begin Activity does not create a live attempt. Training content and prerequisite states are sample data.

Previous versions remain unchanged. Source generator: previews/build_military_flow.py with military-flow.css.
The Layout selector switches between Sidebar and Top navigation (the friendly layout with military styling). The overview selector synchronizes embedded screens. Layout persists through navigation independently of light/dark mode. Use ?layout=topnav for a direct comparison link.
