# My friendly Project Ares section demonstration

I am exploring a friendlier visual direction. This is not the intended or final layout. Navigation only lets reviewers inspect each section.

Open index.html for all five embedded screens, or open the separate pages. Light and dark themes are available. Begin Activity ends the preview; it does not create an attempt. All training content is illustrative.

I referenced these Mobbin examples for learning-card hierarchy, clear next actions, and color blocks. Illustrations here are original SVGs.
- Uxcel: https://mobbin.com/screens/54c0aa01-9380-4e13-bc41-01e46dba6812
- Coursera: https://mobbin.com/screens/18683325-d982-4756-b06e-4ed52c933b06
- Codecademy: https://mobbin.com/screens/6b452ce5-0b98-42e6-84df-7a5f45b42beb

Figma: https://www.figma.com/design/Niz8y7B5viQ3kRd6Mr0pj9?node-id=387-2432

My 24-second Pip introduction appears after the preview notice, before training selection. The original animated shield robot explains Programs, Learning Paths, modules, and briefings. The MP4 has on-screen captions and no audio; it is embedded in the overview and Choose training HTML. Playback is user-initiated, with pause, replay, skip, and a transcript. It is shown once per browser tab session and remains available through Watch introduction.
