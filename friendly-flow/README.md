# My friendly Project Ares section demonstration

I am exploring a friendlier visual direction. This is not the intended or final layout. Navigation only lets reviewers inspect each section.

Open index.html for all five embedded screens, or open the separate pages. Light and dark themes are available. Begin Activity ends the preview; it does not create an attempt. All training content is illustrative.
